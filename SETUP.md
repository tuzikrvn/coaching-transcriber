# Запуск Транскрибатора сессий

## Что нужно сделать один раз

### 1. Получить API-ключ AssemblyAI
1. Зайди на https://www.assemblyai.com/ и создай аккаунт
2. После регистрации сразу дают $50 бесплатного кредита (≈ 80 часов аудио)
3. На главной странице скопируй свой **API Key**

### 2. Загрузить код на GitHub
1. Зайди на https://github.com и создай новый репозиторий (New repository)
2. Назови его, например, `coaching-transcriber`
3. Загрузи все файлы из этой папки в репозиторий

Если не знаешь как — самый простой способ через браузер:
в репозитории нажми **Add file → Upload files** и перетащи все файлы.

### 3. Задеплоить на Render
1. Зайди на https://render.com и создай аккаунт (можно через GitHub)
2. Нажми **New → Web Service**
3. Выбери свой репозиторий `coaching-transcriber`
4. Render автоматически найдёт файл `render.yaml` и всё настроит
5. Нажми **Create Web Service**

### 4. Добавить API-ключ в Render
1. В настройках сервиса на Render найди раздел **Environment**
2. Добавь переменную: `ASSEMBLYAI_API_KEY` = (твой ключ из шага 1)
3. Нажми **Save Changes** — сервис перезапустится

После этого Render даст тебе ссылку вида:
`https://coaching-transcriber.onrender.com`

Эту ссылку отправь жене — она работает из любой страны.

---

## Как пользоваться (для жены)

1. Открыть ссылку в браузере
2. Перетащить аудиофайл на страницу (или нажать и выбрать)
3. Нажать **Начать транскрибацию**
4. Подождать 1–3 минуты
5. Скачать готовую таблицу `.xlsx`

### Поддерживаемые форматы файлов
MP3, MP4, M4A, WAV, FLAC, OGG, AAC — всё что выгружает Zoom

---

## Что в таблице

**Лист «Транскрипция»:**
- Начало и конец каждой реплики (формат MM:СС)
- Длительность в секундах
- Кто говорит (Собеседник А / Собеседник Б)
- Текст реплики
- Паузы выделены жёлтым; паузы ≥ 5 сек — ярко-жёлтым

**Лист «Сводка»:**
- Общая длительность записи
- Количество реплик и пауз
- Процент времени речи каждого собеседника
- Средняя и максимальная пауза

## Стоимость

AssemblyAI берёт $0.01 за минуту аудио (с диаризацией спикеров).
Часовая сессия ≈ $0.60.
Стартового кредита $50 хватит примерно на 80 часов записей.

---

## Если сервис долго не отвечает

Render на бесплатном тарифе "засыпает" после 15 минут простоя.
Первый запрос после паузы может занять 20–30 секунд — просто подождать.
Как только страница загрузится, всё работает нормально.
